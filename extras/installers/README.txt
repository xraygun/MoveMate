Installer files for MoveMate's Installers button (Advanced > Show the Installers button).
Save .msi / .exe / .cmd installers in this folder (MoveMate\extras\installers) and MoveMate runs them from here - no
downloading on each PC. List them in ..\installers.csv (File = the file name), or use "Edit list..." > "Add installer
file..." in MoveMate. A file on a server can be listed with its full path instead (\\server\share\setup.exe).
'Run from this PC' copies the list, not these files (they can be big) - they stay with MoveMate on the stick or share.
